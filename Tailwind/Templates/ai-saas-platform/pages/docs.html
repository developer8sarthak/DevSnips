Getting started

Quickstart

Get from zero to your first streamed completion in under five minutes.

5 min ·Last updated Aug 2026

1. Install the SDK

Install the Nexus AI SDK for your language. All SDKs are open source and fully typed.

bash
npm install @nexus/sdk
# or
pip install nexus-ai

2. Get an API key

Create a project in the dashboard and copy your API key. Store it as an environment variable — never commit it to source control.

bash
export NEXUS_API_KEY="nx_live_********"

3. Make your first request

Initialize the client and run a completion. The same code works across every provider — just change the model alias.

typescript
import { Nexus } from "@nexus/sdk";

const nexus = new Nexus(process.env.NEXUS_API_KEY);

const res = await nexus.complete({
  model: "smart-chat",
  input: "Explain vector search in one sentence.",
});

console.log(res.text);

4. Stream tokens

For real-time UX, stream the response token by token. Streaming is first-byte optimized and works across all providers.

typescript
const stream = await nexus.stream({
  model: "smart-chat",
  input: "Draft a release note.",
});

for await (const chunk of stream) {
  process.stdout.write(chunk.text);
}

Run evaluations

Define a golden dataset and a set of metrics, then run regressions before every release. Gate deploys on a quality threshold.

typescript
const result = await nexus.evals.run({
  dataset: "golden-v3",
  models: ["smart-chat"],
  metrics: ["accuracy", "latency", "cost"],
});

// → { accuracy: 0.94, latency: 142ms, cost: 0.02 }
