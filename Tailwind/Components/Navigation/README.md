# Navigation Component Family

A comprehensive collection of 35 premium navigation components for the DevSnips open-source component library. These components are built with pure HTML and Tailwind CSS utility classes.

## Overview

This Navigation family provides solutions for every navigation use case, from simple navbars to complex multi-level menus. Each component is designed to be production-ready, fully responsive, and accessible.

## Usage

Each component is self-contained and ready for direct copy-paste into your projects.

### File Structure
```
Navigation/
├── component-name/
│   ├── code.html      # Component only (no html/head/body)
│   ├── preview.html   # Full page with Tailwind CDN
│   └── metadata.json   # Component metadata
```

### Quick Start
1. Copy the `code.html` content into your project
2. Ensure Tailwind CSS is included in your build
3. Customize colors and spacing using Tailwind classes

## Customization

All components use Tailwind CSS utility classes for easy customization:

### Colors
Replace color classes (e.g., `text-gray-600`) with your brand colors (e.g., `text-blue-600`).

### Spacing
Modify padding/margin classes (e.g., `px-4`, `py-2`) to adjust spacing.

### Icons
Icons use inline SVG paths. Replace with your preferred icon library.
