# Cards Components

A comprehensive collection of 15 card component variants built with Tailwind CSS.

## Components Included

1. **Profile Card** - User profile display cards
2. **User Avatar Card** - Avatar-focused user cards
3. **Product Card** - E-commerce product display cards
4. **Pricing Card** - Pricing table cards
5. **Feature Card** - Feature highlight cards
6. **Testimonial Card** - Customer testimonial cards
7. **Blog Card** - Blog post preview cards
8. **NFT Card** - NFT marketplace cards
9. **Credit Card UI** - Credit card display
10. **Stats Card** - Key metrics display cards
11. **Analytics Card** - Data visualization cards
12. **Team Member Card** - Team directory cards
13. **Course Card** - Online course cards
14. **Event Card** - Event information cards
15. **Notification Card** - Notification display cards

## Customization

All components use Tailwind CSS utility classes and can be customized by modifying the classes directly.

### Grid Layouts

Cards use responsive grid layouts:

```html
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
  <!-- Cards here -->
</div>
```

### Color Customization

Replace color classes (e.g., `blue-600`, `purple-600`) with your brand colors.

## Accessibility

- All images include descriptive alt text
- Interactive elements include focus states
- Text maintains proper contrast ratios
- Proper heading hierarchy maintained

## Contribution Guidelines

1. Keep components semantic and accessible
2. Use Tailwind CSS utility classes only
3. Include hover states for interactive elements
4. Ensure responsive behavior
5. Test with various content lengths
