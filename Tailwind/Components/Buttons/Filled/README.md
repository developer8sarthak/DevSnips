# Button — Filled

Solid color buttons with soft and tonal variants.

## Styles Included

| Style | Description |
|-------|-------------|
| **Filled Primary** | Full saturation solid colors |
| **Soft Background** | Light tints of color (100 shade) |
| **Rounded Full** | Pill-shaped filled buttons |
| **Muted / Tonal** | Neutral gray variations |
| **Filled on Dark** | White/colored fills for dark backgrounds |

## Usage

```html
<!-- Solid Fill -->
<button class="px-6 py-2.5 bg-blue-600 text-white font-medium 
               rounded-lg hover:bg-blue-700 ...">
  Solid Button
</button>

<!-- Soft Background -->
<button class="px-6 py-2.5 bg-blue-100 text-blue-700 font-medium 
               rounded-lg hover:bg-blue-200 ...">
  Soft Button
</button>

<!-- Pill Shape -->
<button class="px-6 py-2.5 bg-gray-800 text-white font-medium 
               rounded-full hover:bg-gray-900 ...">
  Pill Button
</button>
```

## Color Intensity Guide

| Variant | Background | Text | Use Case |
|---------|-----------|------|----------|
| Solid | 600 shade | White | Primary actions |
| Soft | 100 shade | 700 shade | Secondary actions |
| Tonal | Gray 100/200 | Gray 700 | Tertiary/muted |
