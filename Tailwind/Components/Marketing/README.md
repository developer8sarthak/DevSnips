# Marketing Components

A comprehensive collection of 15 marketing component variants built with Tailwind CSS.

## Components Included

1. **Hero Section** - Main hero sections for landing pages
2. **SaaS Hero** - Hero sections for SaaS products
3. **AI Product Hero** - Hero sections for AI products
4. **Startup Hero** - Hero sections for startups
5. **Feature Comparison Section** - Feature comparison tables
6. **Pricing Table** - Pricing comparison tables
7. **FAQ Accordion** - FAQ accordions
8. **Customer Logo Wall** - Customer logo showcases
9. **Testimonial Carousel** - Testimonial displays
10. **CTA Banner** - Call-to-action banners
11. **Newsletter Signup** - Email signup forms
12. **App Download Section** - Mobile app promotion sections
13. **Stats Counter Section** - Statistics display sections
14. **Timeline Section** - Company timeline displays
15. **Process Steps Section** - Step-by-step process displays

## Usage

```html
<!-- Include Tailwind CSS -->
```

## Customization

All components use Tailwind CSS utility classes and can be customized by modifying the classes directly.

### Gradient Backgrounds

```html
<!-- Purple to Pink -->
<div class="bg-gradient-to-br from-blue-600 via-purple-600 to-pink-600">

<!-- Dark Gradient -->
<div class="bg-gradient-to-br from-slate-900 via-purple-900 to-slate-900">
```

### Typography

```html
<h1 class="text-5xl font-bold">Heading</h1>
<p class="text-lg text-gray-600">Description text</p>
```

## Accessibility

- Text maintains proper contrast ratios on all backgrounds
- Interactive elements include focus states
- Animations respect reduced motion preferences
- Semantic HTML structure

## Contribution Guidelines

1. Keep components semantic and accessible
2. Use Tailwind CSS utility classes only
3. Ensure mobile responsiveness
4. Test with various content lengths
5. Maintain consistent spacing and typography
