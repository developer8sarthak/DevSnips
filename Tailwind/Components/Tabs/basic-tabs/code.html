Overview

DevSnips Tabs are accessible, keyboard-friendly content switchers built with semantic HTML and Tailwind utilities. Use them to organize related content into focused, scannable sections without overwhelming a single page.

Installation

Copy the component markup into your project. No build step is required when using the Tailwind CDN; for production, include the classes in your compiled stylesheet.

Usage

Each tab controls a corresponding panel. Click a tab to reveal its content, or navigate with the arrow keys and activate with Enter or Space.

API Reference

Tabs follow the WAI-ARIA tab pattern: a tablist contains tab elements that control tabpanel regions via aria-controls.
