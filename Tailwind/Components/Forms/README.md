# Forms Components

A comprehensive collection of 15 form component variants built with Tailwind CSS.

## Components Included

1. **Login Form** - User authentication forms
2. **Register Form** - User registration forms
3. **Forgot Password Form** - Password reset request forms
4. **Multi-Step Form** - Multi-step wizard forms
5. **Search Input** - Search bar components
6. **Floating Label Input** - Floating label form inputs
7. **Password Input with Toggle** - Password inputs with visibility toggle
8. **OTP Input** - One-time password inputs
9. **File Upload Component** - File upload interfaces
10. **Drag & Drop Upload** - Advanced drag and drop upload
11. **Date Picker UI** - Date selection components
12. **Time Picker UI** - Time selection components
13. **Select Dropdown** - Select dropdown components
14. **Multi Select Dropdown** - Multi-select tag components
15. **Checkbox Group** - Checkbox input groups

```html
<!-- Include Tailwind CSS -->
<script src="https://cdn.tailwindcss.com"></script>

```

## Customization

All components use Tailwind CSS utility classes and can be customized by modifying the classes directly.

### Input Styling

```html
<!-- Focus ring -->
<input class="focus:ring-2 focus:ring-blue-500 focus:border-blue-500">

<!-- Error state -->
<input class="border-red-500 focus:ring-red-500">
```

### Validation States

```html
<!-- Success -->
<input class="border-green-500 focus:ring-green-500">

<!-- Error -->
<input class="border-red-500 focus:ring-red-500">
```

## Accessibility

- All inputs have proper labels
- Focus states are clearly visible
- Error states are properly communicated
- Keyboard navigation support

## Contribution Guidelines

1. Keep forms semantic and accessible
2. Use Tailwind CSS utility classes only
3. Include proper label associations
4. Add focus and error states
5. Test keyboard navigation
